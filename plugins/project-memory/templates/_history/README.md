# Histórico

Não é lido automaticamente. Guarda decisões (com premissa e motivo), trajetória (paredes e mudanças de direção), diários por
frente e textos longos colados pela pessoa, na íntegra.

- Nome: `AAAA-MM-DD-tema.md`.
- Frente longa: um diário único, com seções novas no fim (`## AAAA-MM-DD: assunto`); o `AGENTS.md` lista os diários.
- Roteiro de uma página de trajetória: onde estávamos; paredes (tabela: parede, o que mostrou, o que fizemos); decisão da pessoa
  (entre aspas, com data); o que mudou; o que fica aberto e quem decide.
- Blocos encerrados do `NOW.md` e frentes fechadas do `TASKS.md` vêm para cá, e lá fica uma linha com o link.
- Nada se apaga: registro substituído ganha `SUPERSEDED` e o link do que vale.
