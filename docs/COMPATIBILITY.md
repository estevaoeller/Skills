# Compatibilidade

## Claude Code

Distribuicao principal por marketplace. O Claude Code descobre as skills dentro de `plugins/<nome>/skills/`.

## Codex e agentes compativeis com AGENTS.md

Copie a skill ou use os templates contidos no plugin. O projeto inicializado inclui `AGENTS.md` e uma copia local em `.agents/skills/project-memory/`.

## Outros agentes

A logica principal esta em Markdown e pode ser adaptada. Scripts e templates permanecem dentro do plugin para que ele seja autocontido.
