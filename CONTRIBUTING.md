# Contribuindo

1. Crie ou altere somente uma pasta autocontida em `plugins/`.
2. Mantenha nomes em `kebab-case`.
3. Atualize `.claude-plugin/marketplace.json`.
4. Execute `python scripts/check_marketplace.py`.
5. Execute `claude plugin validate .` quando o Claude Code estiver instalado.
6. Atualize o README e o changelog quando necessario.
